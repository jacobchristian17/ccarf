Agentic loop & tool_choice

One-page cheat sheet. Taught in Lesson 1.

The loop (TypeScript)

while (true) {
  const res = await client.messages.create({ model, max_tokens, tools, tool_choice, messages });
  if (res.stop_reason === "end_turn") return text(res);          // done
  if (res.stop_reason !== "tool_use") handleOther(res);           // max_tokens, pause_turn, refusal…
  messages.push({ role: "assistant", content: res.content });     // verbatim
  messages.push({ role: "user", content: res.content
    .filter(b => b.type === "tool_use")
    .map(b => run(b)) });                                          // ALL results, ONE message
}

tool_result rules

  • Shape: {type:"tool_result", tool_use_id, content?, is_error?}
  • The results go in the user message immediately after the assistant tool_use turn
  • tool_result blocks come first; any text goes after them (text first → 400)
  • One result per tool_use id, never dropped. A failure is is_error: true
  • Parallel results go in one message; splitting them teaches Claude to stop parallelizing

stop_reason

ValueAction
tool_useRun tools, append results, continue
end_turnFinished; return the answer
max_tokensTruncated; retry with a higher limit
pause_turnServer-tool pause; resend the assistant turn unchanged
refusalDeclined; read stop_details
stop_sequenceCustom stop sequence hit
model_context_window_exceededContext full; treat as truncated

Termination anti-patterns (exam)

  1. Parsing natural language ("done", "final answer")
  2. Iteration cap as the primary stop (a cap as a backstop is fine)
  3. "Response has text → finished"

tool_choice

ValueGuaranteeUse when
autoNone; may reply with textNormal agent turns
anySome tool is calledSeveral schemas, unknown doc type
{type:"tool",name}That tool is calledMust run X first (turn 1 only, then auto)
noneNo tools—
  • any/tool → no text before tool_use (the turn is prefilled)
  • Forced choice on every turn → end_turn never arrives → infinite loop
  • disable_parallel_tool_use goes inside tool_choice: auto ≤ 1 call, any/tool exactly 1
  • Manual extended thinking supports only auto/none
Exam vs reality Exam: any/forced = guaranteed tool call. Reality: Opus 5.5 / Sonnet 5.5 / Fable 5.1 return a 400 for both. Use auto + strict: true, or structured outputs (output_config.format).
