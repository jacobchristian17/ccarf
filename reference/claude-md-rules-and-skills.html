The files are concatenated, not overridden: root-down, the closest file is read last, and conflicts are resolved arbitrarily. A new teammate missing instructions means they're in somebody's user-level file.
@path resolves relative to the importing file, up to 4 hops. It's ignored in code spans and blocks, and imports from outside the project ask for approval the first time. An imported file costs as much context as pasting it in.
Verify: /memory (exam: which memory files are loaded) · /context → Memory files (lazy loads don't appear) · InstructionsLoaded hook (load_reason: session_start · nested_traversal · path_glob_match · include · compact).

Path-scoped rules (3.3)

---
paths:
  - "src/api/**/*"
  - "**/*.test.*"          # YAML list of quoted globs; braces work: "src/**/*.{ts,tsx}"
---
# API + test conventions …

No frontmatter → loads at launch, like .claude/CLAUDE.md. With paths → loads when Claude touches a matching file (exam: "editing"; today: Read, Write or Edit), once per session. Overlapping globs stack (src/web/**/*.tsx also matches *.test.tsx). ~/.claude/rules/ works for personal rules.

Commands and skills (3.2)

Team (git)Personal
Command.claude/commands/review.md → /review~/.claude/commands/
Skill.claude/skills/review/SKILL.md~/.claude/skills/my-review/
---
name: impact-scan
description: Find everything that depends on a symbol before changing it. Use before renames.
argument-hint: "<symbol or file path>"     # prompts for params; body reads $ARGUMENTS · $0 · $1
context: fork                              # isolated subagent; only the result returns
agent: Explore                             # Explore · Plan · general-purpose (default) · .claude/agents/x
allowed-tools: Read, Grep, Glob            # exam: restricts · today: pre-approves only
disallowed-tools: Write, Edit, Bash        # today: what actually removes tools
---
Map the impact of changing `$ARGUMENTS`. Return at most 12 lines. Do not paste file contents.

Skill vs CLAUDE.md: CLAUDE.md is always loaded, for universal standards. A skill is on demand, for task workflows: only its description sits in context until it's invoked. Fork it when output is verbose (codebase analysis) or exploratory (brainstorming alternatives). Other fields: disable-model-invocation: true (only a person can run it), user-invocable: false, model, paths.
Name clash: enterprise > personal > project, so a personal skill with the team's name shadows it. A skill beats a command with the same name.
