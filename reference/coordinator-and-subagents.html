Coordinator & subagents

One-page cheat sheet. Taught in Lesson 4.

Hub and spoke (1.2)

Coordinator jobGoodFailure to spot
DecomposeFull breadth; distinct subtopics / source types per agentToo narrow (sample Q7: only visual arts); duplicated work
SelectEffort scales to the query (1 fact → 1 searcher)Always the full pipeline
DelegateComplete prompts; parallel spawns in ONE responseOne spawn per turn; vague prompts
RefineCheck synthesis for gaps → targeted re-delegation → re-synthesiseAccepts first output
RouteAll subagent traffic via coordinator: observability, consistent errors, controlled flowSubagents talking directly

Root-cause rule: if every subagent did its assigned job well and the output is still wrong, the fault is in the assignment (the coordinator).

Context passing (1.3)

  • Subagent sees: its AgentDefinition.prompt + the Agent call's prompt (+ tool defs, project CLAUDE.md). Not the parent's history, tool results or system prompt.
  • Repeat the user's constraints in every subagent prompt.
  • Synthesizer gets complete findings, structured: { claim, evidence, source: { id, publisher, published, page } }. Prose summary = provenance lost.
  • Coordinator prompt = goals + quality criteria, not numbered steps. Each delegation: objective, output format, tools/sources, boundaries.
